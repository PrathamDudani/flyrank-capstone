warehouse (March 2026). Transcribed directly from Colab output — this file
is the source of truth the paper's numbers are drawn from.

## Model comparison — macro-F1
| Validation set | Majority | Heuristic | Model alone | Hybrid |
|---|---|---|---|---|
| Time-holdout (same pages) | 0.194 | 0.299 | **0.633** | 0.452 |
| Page+time holdout (unseen pages) | 0.194 | 0.298 | **0.632** | 0.452 |

Model accuracy: 70.0% (time-holdout), 69.7% (page+time holdout).
**Final policy: model alone** — the hybrid override that won on synthetic
data underperforms here; reversal documented in the paper's Results section.
